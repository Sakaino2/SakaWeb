## Project Summary

Project developed for the Municipality of Lima that consisted of creating a web interface connected to the API using Astro, React and Tailwind, with features such as summaries and data updates that would be used mainly by inventory managers to track the project's progress.

### Features

- User authentication.
- Role-restricted views.
- Data input validation.
- Inventory progress summaries through a dashboard.
- Report downloads.

### Project Process

It started with the design of the interface in Figma to guide the design of the pages to be created and ensure they fit the project's needs.

### Learnings

Implementing a shadcn/ui component library to achieve an attractive interface with a great user experience.
