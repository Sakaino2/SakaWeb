## Project Summary

Personal responsive web portfolio project using Astro and React (Shadcn) to showcase personal projects using Astro content collections.

### Features

- Use of Astro content collections.
- Use of Shadcn for component design.
- Use of Tailwind for styling.

### Design Process

I started by designing a simple wireframe and listing the components I would need to begin production using the Shadcn library to speed up the implementation process.

### Learnings

Efficient use of libraries as a foundation to speed up development.
