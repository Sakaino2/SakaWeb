## Project Summary

Project developed for the Municipality of Lima that consisted of creating a mobile application based on Flutter/Dart to be used by inventory takers in the field, which would reduce the workload of data entry staff and make the entire inventory process easier.

### Features

- User authentication.
- Creation of folios in which assets would be registered.
- Asset search and registration.
- Search with barcode scanning.
- Taking photos to be uploaded to the backend.
- Offline mode with data synchronization.

### Project Process

It started with the design of the interface in Figma to guide the design of the pages to be created and ensure they fit the project's needs.

### Learnings

Using state management libraries such as Bloc to update the data of the entire application quickly and efficiently.
