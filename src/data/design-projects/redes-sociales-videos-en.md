## Project Summary

Video editing work for social media for restaurants and real estate companies.

### Features

- Use of motion graphics to create dynamism.
- Keeping each brand's visual identity.

### Design Process

The brief specified by other areas was followed to edit the videos, and ideas were proposed to improve the presentation.

### Learnings

When handling multiple projects, it was important to prioritize organization and create a pipeline to speed up video editing.
